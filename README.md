## ¿Qué es Elemental W?

Elemental W es una aplicación web orientada a la enseñanza de ciencias básicas. Une una experiencia de aprendizaje para estudiantes con herramientas que ayudan a docentes a comprender mejor los procesos, dificultades y avances de sus grupos.

Este sitio reúne el proyecto y sus investigaciones. La plataforma principal es el lugar para aprender, practicar y explorar.

> **Aprender ciencias puede ser más cercano, interactivo y significativo.**

## Una experiencia para cada rol

| Para estudiantes | Para profesores | Para la investigación |
| :-- | :-- | :-- |
| Practicar, identificar falencias y fortalecer lo aprendido con múltiples opciones. | Comprender mejor al grupo y decidir qué reforzar en clase. | Recoger evidencia mediante encuestas, entrevistas y uso de la plataforma para mejorar con criterio. |

## Lo que encontrarás

- **Experiencias de aprendizaje** para ciencias básicas.
- **Práctica autónoma** con clases, minijuegos y evaluaciones.
- **Investigaciones educativas** que conectan la tecnología con las necesidades reales de estudiantes y docentes.
- Una plataforma en evolución, construida para aprender mejor y tomar decisiones pedagógicas basadas en evidencia.

## El proyecto

Elemental W nace como una iniciativa de investigación educativa y continúa evolucionando como una plataforma modular. Su propósito es conectar la enseñanza de las ciencias básicas con evidencia sobre cómo aprenden realmente los estudiantes.

Actualmente, el proyecto reúne **2 investigaciones realizadas** con la participación de **82 estudiantes**.
